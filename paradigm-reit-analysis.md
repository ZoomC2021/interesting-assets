### 4.2 Gearing Ratio Analysis

| Metric | Value | Regulatory Context | Assessment |
|--------|-------|-------------------|------------|
| Current Gearing | 36.3% [D:107] | vs 50% limit [D:33] | 🟢 Conservative |
| Headroom Available | 13.7% [D:108] | RM 331M capacity | 🟢 Significant |
| Maximum Capacity | 50.0% | Regulatory ceiling | Buffer maintained |

**Gearing Calculation:**
```
Gearing Ratio = Total Borrowings / Total Assets
              = RM 880M / RM 2,420M
              = 36.36% ≈ 36.3% ✓

Headroom = 50.0% - 36.3% = 13.7%
Unused Capacity = 13.7% × RM 2,420M = RM 331M
```

**Assessment Notes:**
- 36.3% gearing sits well below 50% regulatory threshold
- 13.7% headroom provides RM 331M dry powder for acquisitions
- Conservative positioning aligns with newly listed REIT prudent approach
- Buffer protects against property valuation cyclicality
